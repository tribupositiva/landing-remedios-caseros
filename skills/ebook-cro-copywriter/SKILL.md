# Ebook CRO Copywriting Framework

Esta skill proporciona las directrices, fórmulas probadas y patrones psicológicos para redactar textos de altísima conversión (CRO) para ebooks.

---

## 1. Reglas Fundamentales de Copy CRO para Ebooks

1. **El "Test de la Transformación"**:
   - ❌ *Incorrecto:* "Un libro de 120 páginas con recetas de jugos verdes."
   - ✔️ *Correcto:* "Cómo desinflamar tu abdomen en 7 días y recuperar tu energía matutina sin dietas extremas ni pasar hambre."
2. **CTAs en Primera Persona del Lector**:
   - Siempre redactar los botones desde el deseo del comprador:
     - `¡Sí! Quiero Descargar Mi Copia Ahora Mismo →`
     - `Quiero Aprender Estos Secretos Hoy por Solo $X →`
     - `Garantizar Mi Acceso Inmediato Con 50% OFF →`
3. **Fascinations (Bullet Points Hipnóticos)**:
   - Todo bullet point debe iniciar con las primeras **2 a 3 palabras en negrita**.
   - Usar la estructura: `[Beneficio/Secreto] + [Sin dolor común] + [Página/Capítulo]`.
   - *Ejemplo:* **El error fatal (pág. 24)** que comete el 89% de las personas al intentar desintoxicarse y por qué arruina tu metabolismo.
4. **Reducción Extrema de Fricción**:
   - Al lado o debajo de cada botón CTA siempre deben figurar 3 micro-garantías:
     - ⚡ Descarga inmediata en formato PDF / ePub (dispositivo móvil o PC).
     - 🔒 Pago 100% cifrado y seguro vía SSL.
     - 🛡️ Garantía incondicional de devolución de dinero de 30 días.

## 3. Fórmulas de Headlines Probadas

- **Fórmula de Resultado Rápido:**
  > *"Cómo [Lograr resultado soñado] en [Tiempo determinado] sin [Dolor/Obstáculo principal]"*
- **Fórmula de Revelación Secreta:**
  > *"Los secretos poco conocidos de [Nicho] que los expertos no quieren que descubras para [Beneficio definitivo]"*
- **Fórmula de Advertencia / Prevención:**
  > *"Si vas a [Acción clave], lee esto primero: La guía paso a paso para evitar [Peligro o pérdida]"*

## 4. Estructura del Value Stack (Valor Percibido vs. Precio)

Para maximizar la conversión, el valor acumulado debe superar por 5x a 10x el precio de venta real:

| Elemento | Descripción | Valor Real Estimado |
| :--- | :--- | :--- |
| **Ebook Principal** | Guía Completa Paso a Paso | \$47.00 |
| **Bono #1** | Plantilla / Checklist Imprimible | \$27.00 |
| **Bono #2** | Guía de Inicio Rápido en 15 Minutos | \$19.00 |
| **Bono #3** | Acceso a Comunidad / Actualizaciones | \$37.00 |
| **VALOR TOTAL REAL** | | **\$130.00** |
| **PRECIO HOY (OFERTA ESPECIAL)** | | **SOLO \$17.00** |

## 5. Gatillos Psicológicos Clave para Ebooks

1. **Inmediatez:** Resaltar que el acceso es instantáneo tras el pago (sin esperas de envío físico).
2. **Curiosidad (Information Gap):** Despertar intriga sobre métodos o secretos específicos dentro del libro.
3. **Inversión Mínima vs. Costo del Error:** Contrastar el precio simbólico del libro con lo costoso de seguir cometiendo el mismo problema.
4. **Inversión de Riesgo:** Garantía total del 100% del dinero sin preguntas.
